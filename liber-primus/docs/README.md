## A note on page numbering

Three overlapping schemes are in circulation and they do **not** differ by a constant.
This project uses the **krisyotam canon: 57 segments, 0–56**, in which the unsolved
corpus is segments **0–54**, segment 55 is AN END and segment 56 is PARABLE (both solved).
Divergence from relikd is not a clean −1 — relikd keeps the pp49–51 base-60 table as three
physical pages that krisyotam omits, so relikd runs +3 ahead past the table. Older docs in
this folder may use the release filenames (`0.jpg`–`55.jpg`) instead; see
[`SOLVED-PAGES-AND-INTERRUPTERS.md`](SOLVED-PAGES-AND-INTERRUPTERS.md) for the full mapping.
