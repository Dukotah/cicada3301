## Root cause (observed, not suspected)

Team activity log: **`You deleted project skyfling` at 1793742421800 =
2026-11-03T21:47:01Z** — about 24 minutes before this lane's first API call. Deleting the
project destroyed all three preservation copies named in R42-S1 RESULTS.md:
the original snapshot `snap_ff0SWU76EW32OqbWJvp00fnORypR`, the manual snapshot
`snap_Rw1QyGFA39to1dV9rR8qA8WJEgm6`, and the persistent sandbox
`r42-s1-recovery:/vercel/w/S1-recovered/`.

- **The R42-S1 verdict does not depend on the lost lists.** The load-bearing artifacts are
  local and sha-verified: `STATUS.json` (sha256
  `1aa529444548e3e1f3add420936ddfd40ee9b9fe4cb6d25b74c197a2e070c2ba`, byte-exact vs the
  sandbox), `HIT-CANDIDATE.json` (`b05fd0ba..`, `hits:[]`), and `candidates_summary.json`.
  The verdict (no survivor, best pmax 7.3071 < 7.5342 near-miss bar, coverage 52.054 pp)
  stands unchanged.
- What is lost is only the per-candidate detail below the summary: the full 38,576-row
  `candidates.jsonl` (sandbox sha `bd5c8289..`), `top_S2.json` (`f60eece8..`),
  `hist_S2.u64` (`60c1744a..`). Those rows can only be regenerated by re-running the S2
  window-2 sweep from its engine state, which no longer exists either.
- **Recommendation: accept the lapse.** Manual export before 2026-11-09 is no longer an
  option — the deadline is moot because the source was destroyed on 2026-11-03, not expired.
  Record the shas above as the permanent fingerprint of the lost files; if any future work
  claims to need the full lists, it must re-run the sweep, not recover them.
- Process note for future lanes: a "persistent sandbox + snapshot" is not durable storage —
  it is project-scoped and one project deletion away from vanishing. Anything load-bearing
  must be pulled to the repo (or at least committed shas + summaries, as was done here)
  before the lane closes.
