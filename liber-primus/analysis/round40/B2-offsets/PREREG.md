## Offset / sign arithmetic (exact)
Let R[0..n) be the `$RANDOM` values a shell emits after `RANDOM=seed` (anti-repeat loop applied from the seed, last=0), K_raw[i] = R[i] % 29. A cell (k, s) says: ciphertext C[0] is paired with K_raw[k]; the decode relation is p = c - K_raw[k+j] (s = -1, the repo convention: encipher c = p + K) or p = c + K_raw[k+j] (s = +1: encipher c = p - K).
Implementation: define the effective keystream K'[j] = K_raw[k+j] if s = -1, else (29 - K_raw[k+j]) % 29. Everything downstream (pf_v4_12 head Viterbi, beam_v3 with its own sign=-1 and the keyskip advance 1/2) then runs on K' unchanged: the keystream index starts at k for the ciphertext C[0]; key skips advance the index from there. In the vectorised head screen `heads(seeds, m+k, variant)` is computed over m+k steps (anti-repeat NOT applied, as in R32/R37; the heads are an approximation the skip tolerance absorbs), the first k rows are dropped and, for s = +1, rows are negated mod 29, BEFORE the Viterbi sees them. The full-stream decode uses the exact stream with anti-repeat from the generator start (so the discarded k draws participate in the anti-repeat state exactly as in a shell that has read $RANDOM k times). Plants are enciphered from the TRUE (un-negated) K_raw[k:] with the true sign using `skipdecode.encipher_keyskip(sign=s)` / an enc_pair with c = p - s*K, so the control checks the negation shortcut independently. Sanity asserts: (0,-1) wrapper == R37 path on sample seeds.
