## 5. Bars, statistics, flags
- Beam rows: `round36/B1-orbit-12reg/null12.json` POT bars bar(N) = mu + beta ln(N / -ln 0.99) at ACTUAL N (heads screened for head-screen families; rows per relation for direct-beam families) and at declared N = 1e6; keyskip1 and keyskip2 separately. For head-screen families the number of decoded survivors is also reported and a row clearing bar(N=survivors) but not bar(N=screened) is listed as a near-miss.
- Direct rows: two statistics as C3 - per-stream standardised Z family-wise p and raw best-of-family pmax p; a direct row counts only if BOTH p < 0.01.
- Rows: 12-wide SWEEPROW with the 14th `degenerate` field (`AD.to_row(..., with_degenerate=True)`); "best" values exclude degenerate rows (R37 rule: mds <= min-1 or IoC*N >= max+1 of real-language 240-slices; thresholds recomputed here) and the count of degenerate rows is reported. Stock `AD.validate_store` and `validate_ledger.check_r3_store` on the merged row store.
- Clears actual-N -> L=240 -> flagged-for-oracle per HUMAN-ORACLE.md (bundle written); clears actual-N but not declared-N -> near-miss; clearing is never "solved".
