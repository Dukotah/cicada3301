2. KEY-GENERATION PATTERN ANALYSIS
--------------------------------------------------------------------------------
Cipher-family progression across the book is a deliberate DIFFICULTY RAMP:
  plaintext -> keyless Atbash -> Atbash+Caesar(3) -> Vigenere(themed word)
  -> number-theoretic totient keystream.
Each new page teaches the next primitive. Page 05 explicitly *names* the two
primitives that then appear (primes, totient) and is a plaintext "manifesto."

KEY-SELECTION RULE (the load-bearing finding): every keyed page whose key is a
WORD uses a key that is a THEMATIC word drawn from the Liber Primus's own
vocabulary, and in both solved cases the word is present in / titles the
surrounding plaintext:
  - Page 03-04 key = DIVINITY  (the book's core concept; titles page 10-13).
  - Page 14-15 key = CIRCUMFERENCE (appears verbatim in that page's own koan:
    "THE VOICE OF THE CIRCUMFERENCE"), rune-spelled as FIRFUMFERENFE.
The keyword is NOT arbitrary and NOT an external text -- it is the page's own
theme word, encoded in the Gematria Primus (with the C->F spelling convention).

RUNE-SPELLING CONVENTION (quantified): the C->F substitution is systematic.
CIRCUMFERENCE idx = [5,10,4,5,1,19,0,18,4,18,9,5,18]; FIRFUMFERENFE idx =
[0,10,4,0,1,19,0,18,4,18,9,0,18]. The three differing positions are exactly the
three C's, each replaced by F (index 0 = the interrupter rune). So the author's
KEY WORDS are spelled in the same F-heavy runic orthography as the interrupter.

GEMATRIA/TOTIENT PROPERTY OF THE KEYWORDS -- TESTED, NEGATIVE:
  Prime-value (Gematria) sums:
    DIVINITY=376 (not prime), CIRCUMFERENCE=398 (not prime),
    FIRFUMFERENFE=365 (not prime), WELCOME=317 (PRIME).
  Across 24 thematic words only 5 have prime Gematria sums (WELCOME, PILGRIM,
  EMERGENCE, PARABLE, JOURNEY) = 21%, indistinguishable from the base rate of
  primes in that magnitude band. => Keywords are chosen SEMANTICALLY (by theme),
  NOT by any Gematria/prime/totient numeric property. (Honest null; do not build
  a "keyword must be prime-gematria" hypothesis on this.)
  NOTE: solved_plaintext.txt DOES annotate WELCOME=317, WELCOME PILGRIM...=2113,
  etc. -- these are the author's own Gematria sums of the PLAINTEXT LINES, a
  self-consistency Easter egg, not a key-derivation rule.

PAGE-TO-PAGE DERIVATION (key of N from key of N-1) -- NOT OBSERVED. DIVINITY and
CIRCUMFERENCE are independent theme words, not a chained progression. No key is
derived from a prior page's key or plaintext.

INTERRUPTER RULE (uniform across ALL keyed pages):
  - Only ᚠ (F, index 0, prime 2) is ever a null.
  - Not every ᚠ is null; a per-page subset is (7 on p03, 2 on p14).
  - A null ᚠ is removed from readable plaintext and does NOT advance the
    keystream (no key letter / prime / totient step consumed).
  - A non-null ᚠ is enciphered normally and advances the key.
  This F-skip is the SAME mechanism on the Vigenere pages and the totient page --
  a single consistent rule the author reuses everywhere.
