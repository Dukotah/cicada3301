## 2. U2 - LP1's own numbers as a key schedule
LP1 text = the 94 "LP1-0.*" in-book solved sentences of clues.json in id order (726 words; K->C, V->U, ING->NG so that line sums reproduce the published primes, e.g. EXCEPT WHAT YOU KNOW TO BE TRUE = 1009). Gematria Primus value of a word = sum of rune primes (src/lp/gematria.py). Channels: `prime` (rune prime) and `index` (rune index 0..28). Sequences S: `word` (per-word sum), `line` (per text line of data/keys/armada18/cicada_koans_and_lp_sections.txt - the printed LP1 line breaks are not otherwise recorded in the repo: CONVENIENT, not literal), `sentence` (per clues.json LP1 entry), `cumul` (running cumulative per-word sum). Each reduced mod m, m in {29,28}. 4 sequences x 2 channels x 2 mods = 16 variants.
- (a) additive keystream: K[j] = S[(j+o) mod |S|] mod m over the unsolved runes in order (sign +-1; decode plain = C + sign*K through the keyskip beam).
- (b) key-advance schedule: base key K0 = the LP1 rune stream (the "map"); at the start of the k-th ciphertext word (cleartext boundaries) the pointer into K0 jumps by S[k] mod m in addition to +1 per rune: K'[i] = K0[(o + i + sum_{j<=k(i)} (S[j] mod m)) mod |K0|]; o = start pointer 0..7.
Grid: 16 variants x {a,b} x sign x rel x offset 0..7 x page heads {0,1,2} (the key restarts at each page start; L=120 head of unsolved pages 0,1,2; page 0 coincides with the continuous hypothesis) = 16*2*2*2*8*3 = 3,072 decodes.
Control: for each of the 16 variants x {a,b} (32 plants), a held-out EN_MODERN window is enciphered (a: enc_exact/enc_pair on K, alternating rel; b: enc over K' built with the real page-0 word structure) with a random offset, sign -1; the matching decoder at the true parameters must reach L=240 recovery >= 0.90 and pmax >= bar_v3(1e6) at L=120 and L=240. A failing variant is INVALID (not negative).

## 3. U3 - the composed rule  (words are the map / meaning is the road / numbers are the direction)
Written literally, then alternatives. Fixed cipher-side facts: the unsolved text's word boundaries are the cleartext interrupters '-' and '.' only (mapcommon.parse; '/' is a line wrap, not a boundary); they are not keyed. For a page head, ciphertext words c_0, c_1, ... (k restarts at 0 at each page start), lengths l_k, cumulative rune offset r_k (rune index of the word start).
- MAP: the codebook is the LP1 word list W[0..n-1] (n=726 words after dropping the two numerals 1, 2 and merging DON'T; document order); each entry has a Gematria value v(w) (sum of rune primes).
- ROAD ("meaning is the road"): the positional index of ciphertext word k *through* the codebook, i.e. a walk along the map: entry e_k = W[(s + p_k) mod n], with the pointer p_k one of (rho1) p_k = k (words are read against the map in order), (rho2) p_k = r_k (the rune position of the word start: the map laid out as runes), (rho3) p_k = l_k (word length as the lookup key, the R10 L3 length channel). A pointer from the ciphertext word's own gematria sum is not a well-formed cipher (the encipherer would have to solve a fixed point, with no solution for ~1/3 of words) and is EXCLUDED, stated.
- DIRECTION ("numbers are the direction"): d_k = v(e_k) mod M, M in {29,28}, the retrieved entry's NUMBER, applied at the word boundary as a signed (sigma = +-1) advance, in three application modes:
  - A1 additive shift per word: plain = C - sigma*d_k for every rune of word k;
  - A2 cumulative shift ("direction" accumulates along the road): plain = C - sigma*D_k, D_k = sum_{j<=k} d_j;
  - A3 key advance: key stream K'[i] = K0[(r_k + J_k + t) mod |K0|] (K0 = LP1 rune stream = the map, t = offset in word, J_k = sigma*sum_{j<=k} d_j), decoded plain = C - K' through the keyskip beam (rel 1,2).
  The LITERAL composition is rho1 x A3 (the number advances the key through the map at each word boundary); A1/A2 are the "additive shift" alternative the plan names; rho2/rho3 are alternative roads. All 3 rho x 3 modes are searched, all labelled.
Search space per page head {0,1,2}: rho {1,2,3} x M {29,28} x start s {0..28} x sigma {+-1} = 348 settings, x (A1:1 + A2:1 + A3:2 rel) = 1,392 decodes/page; 4,176 total. The start s is a convenience parameter (the clue fixes none; s=0, the first LP1 word, is the literal one).
Control: for each of rho x M x mode (3x2x4 = 24 plants; A3 both rels), a held-out EN_MODERN window enciphered with the independent encipherer (enciphers_u2_u3.py) using page-0 word structure, random (s, sigma); the sweep decoder at the true parameters must reach L=240 recovery >= 0.90 and pmax >= bar_v3(1e6) at L=120 and L=240. Failing cell => INVALID.
